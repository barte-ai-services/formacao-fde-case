# Pitch de domingo

> **Momento:** pitch dos grupos, domingo, 15/11, às **16h30**.
>
> **Prazo:** o roteiro fica pronto antes das 16h30; o tempo total de cada pitch é a definir pela
> coordenação.
>
> **Onde entregar:** no fork do líder do grupo, em `teams/group-N/sunday-pitch.md`, por pull request.
>
> `group-N` é a pasta do seu grupo: `group-1`, `group-2` e assim por diante.

## Como usar este template

1. Copie este arquivo para `teams/group-N/sunday-pitch.md`.
2. Siga os blocos **nesta ordem**. Não pule nenhum.
3. Para cada bloco, escreva o que vai ser dito em tópicos curtos, não um texto corrido.
4. Defina quem fala em cada bloco.
5. Ensaie pelo menos uma vez com cronômetro, quando a coordenação informar o tempo total.
