Confira com /agents: a Athena precisa aparecer na lista

O Ahrena Framework distribui, como plugins do Claude Code, as regras, skills e agentes que o time usa. A Athena recebe a issue, planeja e entrega a cada builder a camada dele; o Argos revisa antes de cada PR, e as camadas viram PRs empilhados que entram na main em ordem. No curso, abrir a pasta no Claude Code e aprovar os plugins basta para ter o time.
