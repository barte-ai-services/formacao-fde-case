Abra o PR contra o upstream.

Peça ao Claude Code.

No Claude Code, dentro da pasta do seu fork

“Abra o pull request para enviar a minha análise para o upstream.”

O que ele faz por você

1 · Branch

Separa a sua mudança numa branch nova, sem mexer na main.

git switch -c

2 · Commit

Grava o que você alterou, com uma mensagem curta.

git commit

3 · Push

Sobe a branch para o seu fork no GitHub.

git push origin

4 · Pull request

Pede para entrar no original, barte-ai-services, na main.

gh pr create

Leia o PR antes de mandar: título, descrição e arquivos alterados

Por baixo, o Claude Code roda o mesmo que alguém faria à mão: git switch -c para a branch, git add e git commit, git push -u origin para o fork e gh pr create --repo barte-ai-services/formacao-fde-case para abrir o PR no original. Ele mostra cada comando e pede aprovação. Pelo site, o caminho é Compare & pull request no seu fork, com base em barte-ai-services/formacao-fde-case.
