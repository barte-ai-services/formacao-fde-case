Git fork

O fork é a sua cópia.

Você trabalha nela e entrega por PR.

1

Original

Na org barte-ai-services. Você sincroniza o que está aqui.

→

2

Seu fork

Na sua conta do GitHub: Fork → Create fork.

→

3

Clone

git clone do seu fork. É aqui que você edita com segurança.

Receber o que chega

upstream aponta para o original

Sync fork no GitHub, ou 
git fetch upstream, ou
git merge upstream/main.

Entregar

Branch, push e pull request

Você trabalha numa branch do seu fork e 
abre o PR para o fork líder do grupo.

O fork é público: nunca faça commit do .env, de chaves ou de tokens

Cada aluno tem o próprio fork, a cópia do repositório na sua conta. Depois do clone, registre o original como upstream: git remote add upstream https://github.com/barte-ai-services/formacao-fde-case.git. É por ele que chega o que for publicado depois, como o dossiê. O grupo escolhe um fork líder, onde o trabalho se junta; quem é dono dele revisa e faz o merge dos PRs.
