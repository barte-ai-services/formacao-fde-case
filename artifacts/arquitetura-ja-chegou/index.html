Claude Code, um MCP na Cloudflare e o Supabase.

Uma proposta de stack para o grupo partir: o agente roda no Claude Code, as tools do caso ficam num servidor MCP próprio num Cloudflare Worker, e os dados ficam no Supabase. O GitHub guarda o código e publica as duas pontas.

GitHub

Repositório e Actions

O fork guarda o código do Worker e as migrações do Supabase. Cada merge na main publica o Worker e aplica as migrações. O Claude Code também pode rodar num job, com o token do claude setup-token.

Peça a peça

Claude Code

  • Na máquina, entra com a conta de cada um.
  • Fora dela, num job ou servidor, usa um token de longa duração da assinatura, gerado uma vez.
  • O servidor MCP entra como qualquer outro, apontando para a URL do Worker.
# token de longa duração, para jobs
claude setup-token
# no job: CLAUDE_CODE_OAUTH_TOKEN=<token>

# ligar o MCP do caso
claude mcp add --transport http ja-chegou \
  https://ja-chegou-mcp.<conta>.workers.dev/mcp \
  --header "Authorization: Bearer $MCP_TOKEN"

Servidor MCP no Worker

  • Um Worker que fala MCP por HTTP, com as tools do caso.
  • Confere o token Bearer antes de qualquer tool.
  • Os segredos ficam no Worker, nunca no código nem no repositório.
# criar o projeto
npm create cloudflare@latest -- ja-chegou-mcp

# segredos do Worker
wrangler secret put MCP_TOKEN
wrangler secret put SUPABASE_SECRET_KEY

# publicar
wrangler deploy

Supabase

  • Local com Docker para desenvolver, na nuvem para publicar.
  • O esquema vive em migrações versionadas no repositório.
  • Só o Worker conhece a chave secreta. O Claude Code nunca fala direto com o banco.
# local
supabase init
supabase start
supabase migration new criar_tabelas

# nuvem
supabase link --project-ref <ref>
supabase db push --remote

GitHub

  • Fork, branch e pull request, como em qualquer projeto.
  • Actions publica o Worker e aplica as migrações depois do merge.
  • Os tokens da Cloudflare, do Supabase e do Claude ficam nos secrets do repositório.
# secrets do repositório
gh secret set CLOUDFLARE_API_TOKEN
gh secret set CLOUDFLARE_ACCOUNT_ID
gh secret set SUPABASE_ACCESS_TOKEN
gh secret set SUPABASE_DB_PASSWORD
gh secret set CLAUDE_CODE_OAUTH_TOKEN

# actions: cloudflare/wrangler-action@v4
#          supabase/setup-cli@v3
#          anthropics/claude-code-action@v1
