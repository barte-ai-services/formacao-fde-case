# Grupos

Os grupos são formados pelos organizadores antes da imersão: serão 4 ou 5 grupos, de 4 a 5 pessoas cada. Cada grupo tem uma pasta aqui, de `group-1` a `group-5`. Se houver só 4 grupos, a pasta `group-5` fica sem uso.

## O que preencher

No `README.md` da pasta do seu grupo:

- **Nome do grupo**
- **Integrantes**
- **Fork líder**: o link do fork onde o grupo junta o trabalho (por exemplo, `https://github.com/<usuario-do-lider>/formacao-fde-case`)

Preencham no fork líder, por pull request, como qualquer outra entrega do grupo (veja [Como funciona o PR do grupo](../README.md#como-funciona-o-pr-do-grupo)).
